# 恐鬼症鬼魂特征查看器

一个轻量级悬浮窗工具，让你在《恐鬼症》(Phasmophobia) 游戏中快速查看鬼魂特征，无需频繁翻书。

## 🚀 快速开始（开箱即用）

**下载即用，无需安装任何依赖：**

1. 使用打包产物 `dist/恐鬼症查看器.exe`（或从 Releases 下载）
2. 双击运行即可
3. 悬浮窗会自动置顶显示在游戏窗口上方

> 💡 **提示**：程序启动后会显示在屏幕，你可以拖动移动位置。

## ✅ 功能特点

- ⭐ **始终置顶**：悬浮窗始终显示在游戏窗口上方
- 🔎 **快速搜索**：支持按鬼魂名称实时搜索
- 📋 **证据筛选**：证据三态筛选（包含 / 排除 / 未选）
- 📖 **详细信息**：危险等级、猎杀阈值、速度、闪烁、证据、描述、能力、弱点、特征标签
- 🧠 **识别技巧**：每只鬼附带一段中文识别方法（圣木计时、盐堆测试、拍照测试等）
- 🔤 **字号调节**：全局与详情面板字号独立调节，支持 A- / A+ 按钮或直接输入百分比
- 💾 **保存设置**：可选是否保存字号设置，配置保存在系统用户目录
- 🪶 **轻量级**：单文件 exe，数据内置，体积小，启动快

## 🎨 背景色说明

按钮背景色表示不同状态：

| 颜色 | 状态 | 说明 |
|------|------|------|
| ⬜ 灰色 #f0f0f0 | 未选中 | 默认状态 |
| 🟩 绿色 #90EE90 | 选中 | 确认的鬼魂或包含的证据 |
| 🟪 粉色 #FFB6C1 | 排除 | 排除的鬼魂或排除的证据 |
| ⬛ 深灰 #a0a0a0 | 不匹配 | 与当前筛选条件不匹配 |

### 使用方法

1. **点击证据按钮**：切换包含(绿)/排除(粉)/未选(灰)状态
2. **点击鬼魂按钮**：切换选中(绿)/排除(粉)/未选(灰)状态
3. **不匹配的鬼魂**：自动变暗禁用，无法点击

## ⌨️ 快捷键

## 📖 使用说明

### 搜索功能
在搜索框中输入鬼魂名称即可实时筛选列表。

### 证据筛选
- **点击一次**（绿色）：必须包含此证据
- **点击两次**（粉色）：排除此证据
- **点击三次**：恢复未选状态
- 点击"清除筛选"按钮可以重置所有筛选条件

### 鬼魂详情
点击列表中的鬼魂名称即可查看详细信息：
- 基本信息：危险等级（带颜色）、猎杀阈值、移动速度、闪烁频率
- 证据类型
- 描述
- 特征（特殊能力）和缺点（弱点）
- 特征标签
- **识别技巧**：每只鬼的实战识别方法

### 字号调节
- 右上角提供**全局**与**详情**两套字号控制：`A-` / `A+` 按钮，或直接在输入框填写 50–250 之间的百分比后回车
- 全局字号影响标题、按钮、证据列表等界面文字；详情字号只影响右侧鬼魂详情文字

### 保存字号设置
- 勾选「保存字号设置」：调字号后写入配置文件，下次启动恢复
- 取消勾选：每次启动都使用默认 100%，本次临时调整不保存
- 开关状态本身会被记住

## 🛠️ 自定义配置

配置保存在系统用户目录（不在程序文件夹内）：

```
%APPDATA%\恐鬼症查看器\config.json
# Windows 实际路径示例：
# C:\Users\<用户名>\AppData\Roaming\恐鬼症查看器\config.json
```

当前支持的字段：

```json
{
  "font": {
    "scale": 1.0,
    "detail_scale": 1.0,
    "save_scale": true
  }
}
```

- `scale`：全局字号倍率（0.5–2.5，即 50%–250%）
- `detail_scale`：详情面板字号倍率
- `save_scale`：是否保存字号设置（对应界面上的开关）

> ℹ️ 源码目录下的 `data/config.json` 仅为默认模板，运行时不再读取；窗口大小、透明度等参数暂未接入配置（代码中固定）。

## ❓ 常见问题

### 程序无法启动
- 确保下载的是完整的 exe 文件
- 检查杀毒软件是否拦截了程序
- 尝试以管理员身份运行

### 字号每次启动都变回 100%
- 界面右上角的「保存字号设置」未勾选
- 或手动编辑 `%APPDATA%\恐鬼症查看器\config.json` 中的 `font.scale` / `font.detail_scale`

### 数据显示不正确
- 源码运行时确保 `data/ghosts_data_cn.json` 存在且编码为 UTF-8
- exe 版数据已内置，如需覆盖可放一份 `data/ghosts_data_cn.json` 到 exe 同级目录

### 窗口被游戏遮挡
- 程序默认设置为置顶显示
- 如果仍然被遮挡，尝试以管理员身份运行程序

### 方式三：直接运行 Python 脚本
```bash

```

## 📦 打包方法

需要 Python 3 环境并安装 PyInstaller：

```bash
pyinstaller --noconfirm --clean --onefile --windowed --name 恐鬼症查看器 --add-data data;data src\main.py
```

产物在 `dist/恐鬼症查看器.exe`。exe 内置全部数据，可独立运行；如需覆盖数据，可在 exe 同级放一个 `data/` 目录。
