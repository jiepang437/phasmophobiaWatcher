# 恐鬼症鬼魂特征查看器

一个轻量级悬浮窗工具，让你在《恐鬼症》(Phasmophobia) 游戏中快速查看鬼魂特征，无需频繁翻书。

## 🚀 快速开始（开箱即用）

**下载即用，无需安装任何依赖：**

1. 从 Releases 下载
2. 双击运行即可
3. 悬浮窗会自动置顶显示在游戏窗口上方

> 💡 **提示**：程序启动后会显示在屏幕，按住顶部标题栏（👻 恐鬼症鬼魂特征查看器 v2.3 那行）即可拖动窗口。

## ✅ 功能特点

- ⭐ **始终置顶**：悬浮窗始终显示在游戏窗口上方
- 🔎 **快速搜索**：支持按鬼魂名称实时搜索
- 📋 **证据筛选**：证据三态筛选（包含 / 排除 / 未选）
- 🎚️ **难度模式**：普通 / 噩梦 / 疯人院 / 零证据；噩梦与疯人院自动应用"强制证据"推理规则，零证据模式禁用证据筛选
- 🆕 **对局进度追踪**：「开始新对局」一键重置，噩梦/疯人院下状态栏实时显示已确认证据进度，剩 1 只时自动标记"已锁定"
- 💡 **候选鉴别建议**：候选收窄到 2–4 只时，自动列出区分线索（哪个证据锁定哪只鬼）与各候选完整测试方式
- 📐 **可调栏宽**：四栏之间可拖动分隔条，每栏单独拉宽/收窄
- 📖 **详细信息**：危险等级、猎杀阈值、速度、闪烁、证据、描述、能力、弱点、特征标签
- 🧠 **识别技巧**：每只鬼附带一段中文识别方法（圣木计时、盐堆测试、拍照测试等）
- 🔤 **字号调节**：全局与详情面板字号独立调节，支持 A- / A+ 按钮或直接输入百分比
- 💾 **保存设置**：可选是否保存字号设置，配置保存在系统用户目录
- 🪶 **轻量级**：单文件 exe，数据内置，体积小，启动快

## 🎨 背景色说明

按钮背景色表示不同状态：

| 颜色 | 状态 | 说明 |
|------|------|------|
| ⬜ 灰色 #f0f0f0 | 未选中 | 默认状态 |
| 🟩 绿色 #90EE90 | 选中 | 确认的鬼魂或包含的证据 |
| 🟪 粉色 #FFB6C1 | 排除 | 排除的鬼魂或排除的证据 |
| ⬛ 深灰 #a0a0a0 | 不匹配 | 与当前筛选条件不匹配 |

### 使用方法

1. **点击证据按钮**：切换包含(绿)/排除(粉)/未选(灰)状态
2. **点击鬼魂按钮**：切换选中(绿)/排除(粉)/未选(灰)状态
3. **不匹配的鬼魂**：自动变暗禁用，无法点击

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl + F | 聚焦到搜索框 |
| Esc | 缩小为 👻 悬浮窗；已处于悬浮窗状态时按 Esc 无效（不会影响恢复后的大小） |

## 📖 使用说明

### 搜索功能
在搜索框中输入鬼魂名称即可实时筛选列表。

### 证据筛选
- **点击一次**（绿色）：必须包含此证据
- **点击两次**（粉色）：排除此证据
- **点击三次**：恢复未选状态
- 点击"清除筛选"按钮可以重置所有筛选条件

### 难度模式
右上角的难度下拉框支持四种模式，切换后会自动清空证据筛选：

| 难度 | 证据数量 | 说明 |
|------|---------|------|
| 普通 | 3 | 标准玩法，全部 7 种证据可筛选 |
| 噩梦 | 2 | 每只鬼有 1 条**强制证据**必定出现在笔记本上；确认满 2 条证据后，自动排除强制证据不在其中的鬼 |
| 疯人院 | 1 | 同上，但只确认 1 条证据 |
| 零证据 | 0 | 自定义零证据玩法，证据筛选置灰不可用，靠行为特征与识别技巧判断 |

- **强制证据**：御灵→点阵投影仪、幻妖→紫外线、寒魔→刺骨寒温、魔洛伊→通灵盒、雾影→通灵盒、拟魂→灵球
- 查看鬼魂详情时，噩梦/疯人院难度下会标注该鬼的强制证据（⭐ 提示）
- 噩梦/疯人院下最多只能确认对应数量的证据（噩梦 2 条、疯人院 1 条），再点会提示先排除其他证据

### 对局进度追踪
- 每局开始点击搜索栏右侧的 **🆕 开始新对局**：一键清空搜索、证据筛选和鬼魂选择状态，开始全新一局
- 噩梦/疯人院难度下，底部状态栏会显示 **已确认证据 X/槽位数** 的实时进度
- 候选只剩 1 只时，状态栏自动标记 **✅ 已锁定**

### 候选鉴别建议
- 当匹配的候选鬼收窄到 **2–4 只**时，**鬼魂列表与鬼魂详情之间**会自动出现「💡 候选鉴别建议」一列（可滚动），包含两部分：
  - **区分线索**：列出只出现在部分候选身上的证据，并标明每个证据对应哪些候选（看到即可锁定/排除）
  - **完整测试方式**：每只候选直接显示**完整的识别技巧全文**（含测试名，如「灯光测试」「圣木计时测试」），无需逐个点击查看
- 候选超过 4 只或不足 2 只时该列自动隐藏，详情栏会占满剩余空间

### 鬼魂详情
点击列表中的鬼魂名称即可查看详细信息：
- 基本信息：危险等级（带颜色）、猎杀阈值、移动速度、闪烁频率
- 证据类型
- 描述
- 特征（特殊能力）和缺点（弱点）
- 特征标签
- **识别技巧**：每只鬼的实战识别方法

### 字号调节
- 右上角提供**全局**与**详情**两套字号控制：`A-` / `A+` 按钮，或直接在输入框填写 50–250 之间的百分比后回车
- 全局字号影响标题、按钮、证据列表等界面文字；详情字号只影响右侧鬼魂详情文字

### 保存字号设置
- 勾选「保存字号设置」：调字号后写入配置文件，下次启动恢复
- 取消勾选：每次启动都使用默认 100%，本次临时调整不保存
- 开关状态本身会被记住

### 悬浮窗模式
- 按 **Esc** 可将窗口缩小为左上角的 👻 悬浮窗，方便游戏时腾出屏幕空间
- 悬浮窗可以**拖动**到任意位置
- **单击**悬浮窗或右键选择「恢复窗口」即可恢复为原窗口大小与位置
- 右键菜单中的「退出」可以完全关闭程序
- 已处于悬浮窗状态时再按 Esc 会被忽略，不会影响恢复后的窗口大小

## 🛠️ 自定义配置

配置保存在系统用户目录（不在程序文件夹内）：

```
%APPDATA%\恐鬼症查看器\config.json
# Windows 实际路径示例：
# C:\Users\<用户名>\AppData\Roaming\恐鬼症查看器\config.json
```

当前支持的字段：

```json
{
  "font": {
    "scale": 1.0,
    "detail_scale": 1.0,
    "save_scale": true
  }
}
```

- `scale`：全局字号倍率（0.5–2.5，即 50%–250%）
- `detail_scale`：详情面板字号倍率
- `save_scale`：是否保存字号设置（对应界面上的开关）

> ℹ️ 源码目录下的 `data/config.json` 仅为默认模板，运行时不再读取；窗口大小、透明度等参数暂未接入配置（代码中固定）。

## ❓ 常见问题

### 程序无法启动
- 确保下载的是完整的 exe 文件
- 检查杀毒软件是否拦截了程序
- 尝试以管理员身份运行

### 字号每次启动都变回 100%
- 界面右上角的「保存字号设置」未勾选
- 或手动编辑 `%APPDATA%\恐鬼症查看器\config.json` 中的 `font.scale` / `font.detail_scale`

### 数据显示不正确
- 源码运行时确保 `data/ghosts_data_cn.json` 存在且编码为 UTF-8
- exe 版数据已内置，如需覆盖可放一份 `data/ghosts_data_cn.json` 到 exe 同级目录

### 窗口被游戏遮挡
- 程序默认设置为置顶显示
- 如果仍然被遮挡，尝试以管理员身份运行程序
